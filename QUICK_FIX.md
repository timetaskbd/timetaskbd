
# Quick Fix for Database Errors

## The Problem
The `profiles` table is not set up properly in your Supabase project.

## The Solution (1-2 Minutes)

### Step 1: Open your Supabase Project
Go to: https://supabase.com/dashboard/project/kdoouzlmncekkozjrsdf

### Step 2: Open the SQL Editor
Click **SQL Editor** in the left sidebar (looks like a ⚡ or 📝 icon).

### Step 3: Create New Query
Click the **+ New Query** button.

### Step 4: Paste & Run Simple Schema
1. Open `d:\VS Code\Time Task BD\database\simple_schema.sql`
2. Copy **all** the code
3. Paste it into the query editor
4. Click **Run** (▶️)

You should see "profiles table created successfully!"

### Step 5: Verify Table
Go to **Table Editor** in the left sidebar. You should now see a `profiles` table!

### Step 6: Refresh & Register
Refresh the Register Page (F5) and try registering again!
Now the page will show you the exact error details if anything goes wrong.
